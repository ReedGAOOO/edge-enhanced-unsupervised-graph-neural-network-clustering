Project environment declaration
===============================

Default for AI agents:

- Use uv for root graph-neural-network code.
- Use the nested uv project in `reference/urbanity` for urbanity reference
  package work.
- Do not use conda `base`.
- Do not attempt to use the removed shared `gnn` conda environment.

Root graph-neural-network environment:

  uv venv --python 3.11 .venv
  uv pip sync --python .venv/bin/python --torch-backend cu129 requirements.uv.lock.txt

Run root commands with:

  uv run --python .venv/bin/python python <script.py>

Urbanity reference package:

  cd reference/urbanity
  uv sync --locked

Run urbanity commands with:

  cd reference/urbanity
  uv run --locked python <script.py>

Notes:

- The root lock file is generated with PyTorch CUDA 12.9 and PyG wheels from
  https://data.pyg.org/whl/torch-2.8.0+cu129.html. torch is pinned to 2.8.0 so
  it matches the torch-scatter pt28 wheel (torch 2.12 + scatter pt28 aborts with
  std::bad_alloc on import). `--torch-backend cu129` is required for the sync.
- Project data: repo-local data/ is an fstab bind mount of
  /mnt/d/WSL Projects Data/home/aitx/workspace/projects/edge-enhanced-unsupervised-graph-neural-network-clustering/data
  (populated 2026-10-13; see DATA_ASSETS.md). The default --root_path data works.
- The old urbanity conda and Poetry locks are retained only as text backups.
