## 如何解读

早期 60–120 轮实验没有充分训练骨干模型，部分 Urban 评价还把 `unknown` 当作真实类别。归档中的“主线”“最好”“推荐”描述只代表生成时的判断，不能作为当前聚类排名或边语义有效性的证据；当前协议、对照及结论限制见[项目首页](../README.md)。

本次更新维护归档导航，不批量改写历史报告、工作副本或第三方 README。需要追溯时，保留原始命令、代码版本、配置和评价协议一起核对；仅使用旧预设不能恢复当时的完整运行环境。

部分旧 CSV、脚本和符号链接仍含原工作站的 Windows/WSL 绝对路径，旧盘符链接可能已失效。仓库中的说明或链接不代表大文件载荷已随 Git 发布；已知数据位置、备份与限制见 [DATA_ASSETS.md](../DATA_ASSETS.md)。
