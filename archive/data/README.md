# Archived Data

This folder keeps older dataset variants that were moved out of the active `data/` surface.

- `historical/dblp/`: older DBLP graph variants
- `historical/synth_edge_control/`: older edge-control synthetic datasets
- `historical/synth_smoke/`: smoke-only synthetic datasets
- `historical/urban_legacy/`: older urban builder outputs before the current `v3bsjg` recommendation
